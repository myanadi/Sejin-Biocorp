# SEJIN OS v12.4 — 신호성_2099

> A game-style operating system simulation for a Korean cyberpunk 
> megacorporate world.
> Login as an R&D researcher. Navigate folders. Pull files. 
> Trigger a security trace.

🌐 **Live Site**: https://myanadi.github.io/Sejin-Bio/

## Overview

**SEJIN OS** is the internal operating system of Sejin Bionics — 
the dominant megacorporation in the Korean cyberpunk megacity of 
신호성_2099. Visitors log in as an R&D researcher and explore the 
company's internal file system, NPC database, and security 
infrastructure as a playable interactive narrative.

This site is designed as a **transmedia entry point** to a larger 
AI chatbot roleplay session — the security alert triggered inside 
the OS leads directly into the first message of the corresponding 
RisuAI character.

## Concept

- **Three-tier Megacity**: 백야구 (White Night District), 중앙구 
  (Central District), 잠수구역 (Submerged Zone) — stratified by 
  PLC class and credit score
- **Megacorp Internal OS**: Folder structure, command-line 
  interface, file access permissions modeled after real enterprise 
  systems
- **Cross-faction Narrative**: Player is an R&D researcher + 
  MEDX informant — a double identity built into the world
- **Transmedia Routing**: The security trace warning in the OS 
  directly cues the first message of the AI chatbot session

## Key Features

- **Login authentication** with employee ID
- **Folder navigation** through internal departments
- **Command system**: `/help`, `/whoami`, `/query_SUB`, 
  `/msg_recv`, `/disconnect`
- **EXTERNAL SHELL detection** — a live countdown when security 
  detects unauthorized access
- **Cross-platform handoff** — site session continues into AI 
  chatbot narrative

## What This Site Does

- Boots a fictional megacorp OS as a game-like interactive 
  experience
- Builds tension toward a security incident that hands off to 
  a separate AI chatbot session
- Demonstrates how a static site and a generative AI session 
  can share a single continuous narrative thread

## Tech Stack

- HTML / CSS / Vanilla JavaScript
- Static hosting via GitHub Pages
- AI-assisted development workflow (Claude / GPT)

## 한국어 요약

2099년 한반도 동남권 메가시티 사이버펑크 세계관의 거대기업 
**세진 바이오닉스**의 사내 운영체제(SEJIN OS v12.4)를 게임형 
인터랙티브 사이트로 구현했습니다.

사용자는 R&D 연구원으로 로그인하여 사내 폴더 구조와 명령어 
시스템(`/help`, `/whoami`, `/query_SUB`, `/msg_recv`, 
`/disconnect`)을 탐색하며, EXTERNAL SHELL 보안 추적 카운트다운을 
경험하게 됩니다.

이 사이트의 보안 경고 시점이 별도의 AI 챗봇 세션 첫 메시지로 
직결되도록 설계된 **트랜스미디어 라우팅** 구조입니다. 정적 
사이트와 생성형 AI 세션이 하나의 서사를 공유하는 실험.
